# Quotty

Интерактивный и удобный счётчик квот для Claude/Codex/Antigravity/MiniMax/DeepSeek - показывает не только текущий расход лимита, но и то, насколько быстро вы его расходуете.

<img width="700" height="194" alt="quotty_demo" src="https://github.com/user-attachments/assets/4adfc8f7-5468-435d-bb2c-ce5a4624582a" />

Тонкая полоска поверх всех окон: показывает, сколько квоты осталось у ИИ-инструмента, в котором вы сейчас работаете, и когда лимит обнулится.

Полоска сама переключается на тот инструмент, окно которого было активно последним.
Поддерживаются пять семейств:

- **Claude** — приложение Claude Desktop и Claude Code / CLI;
- **Codex** — приложение Codex/ChatGPT и Codex CLI;
- **Antigravity** — Antigravity 2.0 и Antigravity IDE;
- **MiniMax** — подписка M Plan (тариф Go, а также Explore/Build): окна 5 часов и неделя,
  данные из официального эндпоинта MiniMax по ключу подписки;
- **DeepSeek** — баланс официального API в CNY/USD (у DeepSeek оплата деньгами, а не окнами квоты).

MiniMax и DeepSeek не имеют локального приложения, которое можно было бы отследить
автоматически, поэтому их полоска **закрепляется вручную** в настройках — независимо от того,
какое окно сейчас активно.

## Возможности

- Отдельная строка на каждое окно лимита (от 5 часов до месяца — что отдаёт сервис).
- Полоса расхода с белой отметкой времени: видно, тратите вы быстрее или медленнее, чем истекает лимит.
  - зелёная — идёте с запасом, из края расхода поднимаются пузырьки;
  - жёлтая — тратите быстрее, чем идёт время;
  - оранжевая — лимит выбран полностью.
- Точное время сброса и сколько до него осталось.
- Автопереключение по активному окну — включая CLI, запущенный в терминале.
- Настройка непрозрачности (слайдер и готовые значения), режим заголовка: среда и тариф / только семейство / скрыть.
- Работает без кнопки на панели задач: перетаскивание — ЛКМ, настройки — ПКМ по полоске или через трей.
- Проверка обновлений раз в 8 часов по тегу релиза на GitHub.

## Приватность

- **Нет телеметрии.** Ни аналитики, ни счётчиков, ни сбора статистики.
- **Нет рекламы.** Никаких баннеров, партнёрских ссылок и «предложений».
- **Нет серверов автора.** Программа обращается только к API самих сервисов (Anthropic, OpenAI,
  MiniMax, DeepSeek) и к локальному языковому серверу Antigravity на 127.0.0.1.
- Токены читаются локально, из хранилищ уже установленных программ, и уходят только тому сервису, которому принадлежат. Quotty ничего не пишет в чужие файлы и не обновляет чужие токены.
- Ключи MiniMax и DeepSeek вы вводите сами в настройках. Они **не** попадают в `settings.json`,
  в логи и в репозиторий: каждый ключ шифруется Windows DPAPI под вашей учётной записью и лежит
  отдельным файлом `%APPDATA%\Quottyall\<провайдер>.key`. Скопированный на другой компьютер или в
  другой профиль файл не расшифровывается.
- Свои настройки Quottyall хранит в `%APPDATA%\Quottyall\settings.json` — отдельно от
  оригинального Quotty, поэтому настройки обеих сборок не мешают друг другу.
- Единственные сетевые запросы — проверка новой версии на GitHub и опрос включённых источников
  квоты (Claude, Codex, Antigravity, MiniMax, DeepSeek).

## Откуда берутся данные

| Инструмент | Источник |
|---|---|
| Claude | локальный токен Claude Desktop → официальный эндпоинт использования аккаунта |
| Codex | `~/.codex/auth.json` (общий у приложения и CLI) → эндпоинт использования Codex |
| Antigravity | локальный языковой сервер Antigravity — тот же запрос, что делает панель расхода в самой IDE |
| MiniMax | `GET https://www.minimax.io/v1/token_plan/remains` с вашим ключом подписки M Plan (хост CN — по выбору в настройках). Официальный эндпоинт из FAQ MiniMax; те же два окна, что показывает консоль |
| DeepSeek | `GET https://api.deepseek.com/user/balance` с вашим API-ключом: доступный баланс, пополненные и подарочные средства |

Если инструмент не установлен или не запущен, его источник просто помечается как недоступный — остальные продолжают работать.

### Процент у DeepSeek — это не лимит

У DeepSeek API нет ни 5-часового, ни недельного окна: оплата списывается с денежного баланса.
Поэтому Quotty рисует **баланс** (CNY или USD) и закрашивает долю, израсходованную от вашей
базовой суммы — того баланса, который был при первом успешном опросе или после последнего
пополнения. База поднимается автоматически при пополнении и пересчитывается кнопкой в настройках.
Это внутренняя точка отсчёта Quotty, **не** официальный лимит DeepSeek.

## Установка

Сборка этого форка ставится **отдельно от оригинального Quotty** и не перезаписывает его:
у неё другое имя (`Quottyall`), другая папка установки и другой идентификатор установщика.
Скачайте `Quottyall-Setup.exe` со страницы релизов форка и запустите. Установка идёт в профиль
пользователя, права администратора не нужны.

При установке можно сразу включить автозапуск; позже это переключается в настройках или в меню трея.

## Как пользоваться

- **ЛКМ по полоске** — перетащить в удобное место (позиция запоминается).
- **ПКМ по полоске** — открыть настройки (открываются по центру того монитора, где вы находитесь).
- **Меню в трее** — можно настроить и там.
- **Ключи MiniMax и DeepSeek** — в настройках, раздел «Ключи доступа»: вставьте ключ, нажмите
  «Сохранить ключ». Там же галочки «Закрепить … на строке», чтобы полоска показывала облачный
  источник независимо от активного окна, и выбор региона MiniMax (Global / Китай).


## Требования

- Windows 10/11, x64.
- Установленный инструмент, чью квоту нужно смотреть: Claude Desktop, Codex CLI/приложение, Antigravity.
- Для Antigravity — запущенное приложение или IDE (квота живёт в его языковом сервере).
- Для MiniMax — подписка M Plan и её ключ из Plan Details. Для DeepSeek — API-ключ с положительным балансом.

## Сборка из исходников

```
cargo build --release
```

Инсталлятор форка (нужен [Inno Setup 6](https://jrsoftware.org/isdl.php)):

```
powershell -ExecutionPolicy Bypass -File tools\build-installer-fork.ps1
```

Готовый EXE без установщика — `target\release\quottyall.exe`.

Проверка ключей без запуска интерфейса (ключ вводится в маскированный prompt и шифруется DPAPI):

```
powershell -ExecutionPolicy Bypass -File tools\set-key.ps1 -Provider minimax
powershell -ExecutionPolicy Bypass -File tools\set-key.ps1 -Provider deepseek
powershell -ExecutionPolicy Bypass -File tools\probe-providers.ps1
```
